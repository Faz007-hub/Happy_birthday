# 🎂 Happy Birthday Motu! — Birthday Surprise Website

A premium interactive birthday surprise website for **Karshi (Motu)** from **Bhaiyoo**.

## 🌟 Features

- **5-Stage Interactive Experience** — Gift box → Birthday Reveal → Memory Wall → Cute Moment → Grand Celebration
- **Animated Gift Box** with Bhaiyoo popping out
- **Birthday Memory Wall** with 7 personal cards in a scrapbook layout
- **Fireworks & Confetti** celebrations
- **Mouse sparkle trail** effects
- **Background birthday music** with mute/unmute control
- **Fully responsive** — mobile-first design
- **Adorable cartoon characters** — Bhaiyoo & Motu in multiple poses

## 📁 Project Structure

```
hbd/
├── index.html          # Main HTML (all 5 stages)
├── css/
│   └── style.css       # All styles, animations, responsive
├── js/
│   └── app.js          # All JavaScript interactions
├── assets/             # (empty — all assets are inline SVG)
├── vercel.json         # Vercel deployment config
└── README.md
```

## 🚀 Deploy to Vercel

1. Push this folder to a GitHub repository
2. Import the repo in [Vercel Dashboard](https://vercel.com)
3. Vercel auto-detects static site — click Deploy!

Or use Vercel CLI:
```bash
npm i -g vercel
cd hbd
vercel
```
